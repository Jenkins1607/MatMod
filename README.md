## Задача 3
**Прямая задача колебаний маятника: численное и аналитическое решение**

Дано: l = 1 м, g = 9,8 м/с², α₀ = 0,3 рад, α'(0) = 0.

*   **Аналитически (математический маятник):**
    Уравнение: α'' = -(g/l)α
    Решение: α(t) = α₀ cos(√(g/l) · t) ≈ 0,3 cos(3,13t)
    Период: T = 2π√(l/g) ≈ 2,007 с.

*   **Численно (физический маятник):**
    Нелинейное уравнение α'' = -(g/l)sin(α) сводим к системе:
      α' = ω
      ω' = -(g/l)sin(α)
    
    Решаем методом Эйлера–Кромера / Рунге–Кутты:
      ω_{n+1} = ω_n - τ_h · (g/l) · sin(α_n)
      α_{n+1} = α_n + τ_h · ω_{n+1}

Период T_Φ — время между максимумами (с параболическим уточнением); он удовлетворяет оценке:
  2,007 с < T_Φ < 2,516 с
