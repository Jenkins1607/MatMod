### Задача 3

**Прямая задача колебаний маятника: численное и аналитическое решение**

Дано: $l = 1$ м, $g = 9.8$ м/с², $\alpha_0 = 0.3$ рад, $\alpha'(0) = 0$.

* **Аналитически (математический маятник):** Уравнение: $\alpha'' = -\frac{g}{l}\alpha$. Решение: $\alpha(t) = \alpha_0\cos(\sqrt{g/l} \cdot t) \approx 0.3\cos(3.13t)$. Период: $T_* = 2\pi\sqrt{l/g} \approx 2.007$ с.
* **Численно (физический маятник):** Нелинейное уравнение $\alpha'' = -\frac{g}{l}\sin\alpha$ сводим к системе:

$$
\begin{cases} \alpha' = \omega \\ \omega' = -\frac{g}{l}\sin\alpha \end{cases}
$$

Решаем методом Эйлера–Кромера / Рунге–Кутты:

$$
\omega_{n+1} = \omega_n - \tau_h \frac{g}{l} \sin \alpha_n, \quad \alpha_{n+1} = \alpha_n + \tau_h \omega_{n+1}
$$

Период $T_{\Phi}$ — время между максимумами (с параболическим уточнением); он удовлетворяет оценке:

$$
T_* < T_{\Phi} < \sqrt{\frac{\pi}{2}} T_* \approx 2.516 \text{ с}
$$

## Задача 4

### Задача о газетчике: численное и аналитическое решение

Классическая задача оптимального управления запасами при неопределенном спросе. Газетчик закупает $k$ экземпляров по цене $a$ и продает по цене $b$ ($b > a > 0$). Спрос $z$ — случайная величина. Нераспроданные экземпляры имеют нулевую ликвидность; при дефиците теряется потенциальная прибыль.

* **Аналитически:** Для равномерного распределения спроса $z \sim U[\alpha; \beta]$ ожидаемый доход максимизируется в точке:
  $ \frac{\alpha \cdot b_{л} + \beta \cdot a_{л}}{a_{л} + b_{л}} $
  где $a_{л} = b - a$ (доход с проданной единицы), $b_{л} = a$ (убыток с непроданной). Оптимальный объем соответствует квантили уровня $\frac{a_{л}}{a_{л} + b_{л}}$ функции распределения спроса.

* **Численно (Монте-Карло + МНК):** При сложном законе распределения или для верификации используется имитационное моделирование:
  1. Генерируется $N$ реализаций спроса $z_i$.
  2. Оценивается статистическое мат. ожидание дохода: $M_{\text{stat}}(k) = \frac{1}{N} \sum I(k, z_i)$.
  3. «Зашумленная» кривая $M_{\text{stat}}(k)$ сглаживается параболой $P(k) = Ak^2 + Bk + C$ методом наименьших квадратов (МНК).
  4. Численный оптимум находится как вершина параболы: $k_{\text{opt}} = -\frac{B}{2A}$.
