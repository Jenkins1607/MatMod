## Задача 3
**Прямая задача колебаний маятника: численное и аналитическое решение**

Дано: $l = 1$ м, $g = 9,8$ м/с², $\alpha_0 = 0,3$ рад, $\alpha'(0) = 0$.

*   **Аналитически (математический маятник):** $\alpha'' = -\frac{g}{l}\alpha$, $\alpha(t) = \alpha_0 \cos \sqrt{g/l} \cdot t = 0,3 \cos(3,13t)$, $T = 2\pi\sqrt{l/g} \approx 2,007$ с.
*   **Численно (физический маятник):** $\alpha'' = -\frac{g}{l}\sin\alpha$ сводим к системе $\alpha' = \omega$, $\omega' = -\frac{g}{l}\sin\alpha$ и решаем методом Эйлера–Кромера / Рунге–Кутты:
    $$ \omega_{n+1} = \omega_n - \tau_h \frac{g}{l} \sin \alpha_n, \quad \alpha_{n+1} = \alpha_n + \tau_h \omega_{n+1}. $$

Период $T_{\Phi}$ — время между максимумами (с параболическим уточнением); он удовлетворяет оценке $T_* = 2,007 \text{ с} < T_{\Phi} < \sqrt{\pi/2}T_* \approx 2,516 \text{ с}$.
